Aturan navigasi dan tombol

1Menu kiri hanya berisi modul utama, maksimal 7 sesuai peran.
2Halaman di dalam modul dibuka lewat tab di atas konten.
3Pengaturan (harga, diskon, lokasi) ada di menu kiri untuk Owner dan Admin. Log notifikasi dibuka lewat ikon lonceng di pojok kanan atas. Menu profil hanya berisi Keluar. Semua halaman juga bisa dicari lewat pencarian cepat (Ctrl K).
4Setiap layar paling banyak punya satu tombol utama dan satu tombol sekunder. Batal ditulis sebagai teks.
5Aksi per baris tidak memakai tombol. Baris bisa diklik dan membuka detail.
6Semua layar untuk laptop 1440 px. Siaran live tetap di TikTok; dashboard dipakai untuk jadwal dan rekap klaim.
